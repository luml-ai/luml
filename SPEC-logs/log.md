- **Add text editing with a file watcher and agent locks to the daemon** — changed earlier work: File creation, rename and move now report the published file's identity and modification time to the watcher. - **Add text editing with a file watcher and agent locks to the daemon** — Text reads and saves return a content revision alongside the full-precision mtime. A normal save checks both because an external editor can preserve the mtime or change the contents within one filesystem timestamp tick.
