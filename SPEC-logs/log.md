# Apply log

- **Add the file API to the daemon** — spec not followed: The read limit for inspection names only the manifest, dataset info and tar index. Model detection also reads the environment, manifest patches and model metadata JSON because the required fnnx Reader uses them to validate a model. Model weights and dataset chunks stay unread.
- **Add the file API to the daemon** — decided: A listing request above the 2,000-entry limit receives a capped page and the offset for the next page. This lets a caller continue paging with the same requested limit.
- **Add the file API to the daemon** — decided: A dataset with a readable manifest and malformed split metadata still exposes its manifest and archive contents. Its split list is empty when the split definitions cannot be validated, and an unreadable optional row count is reported as unknown.
- **Add the file API to the daemon** — The CLI-delete scenario calls for a bare command with no prompt, while the Design preserves the existing CLI behavior. Deleting a notebook still asks once for destructive confirmation unless invoked with `--yes`. Both forms request `close_open` so an open session needs no second confirmation.
- **Add text editing with a file watcher and agent locks to the daemon** — changed earlier work: File creation, rename and move now report the published file's identity and modification time to the watcher. This lets the watcher refresh the listing without attributing those operations to a leased agent.
- **Add text editing with a file watcher and agent locks to the daemon** — Text reads and saves return a content revision alongside the full-precision mtime. A normal save checks both because an external editor can preserve the mtime or change the contents within one filesystem timestamp tick.
- **Extend the shared attachments preview** — decided: A split with an unknown row count shows the number of rows in its preview, for example “Showing first 1,000 rows”. Using the chunk size as the split total could understate the size of a multi-chunk dataset.
- **Extend the shared attachments preview** — Rendered Markdown suppresses externally hosted report images because opening a preview must not contact another server. Embedded images and self-contained diagrams remain available.
- **Extend the shared attachments preview** — Apache Arrow JS 21.1.0 cannot decode large-list and string-view IPC fields used by PyArrow and Polars. When it rejects a field layout, the preview uses Flechette to read the original values, including nested strings and 64-bit integers.
