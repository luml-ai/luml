<p align="center">Paste this prompt into your coding agent or a chat assistant.<br>It asks about your work, reads your code if it can, and explains where LUML helps.</p>

```text
Read https://raw.githubusercontent.com/luml-ai/luml/main/.agents-onboarding/index.md
and help me understand how LUML could fit my work.
```
