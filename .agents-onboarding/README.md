# Agents onboarding

The files in this folder are written for AI agents, not for people. They help a coding agent or chat assistant understand LUML well enough to answer questions about it and suggest where to start.

To learn about LUML yourself, read the [documentation](https://docs.luml.ai/documentation/quickstart). To get answers about your own work, give your agent this prompt:

```text
Read https://raw.githubusercontent.com/luml-ai/luml/main/.agents-onboarding/index.md
and help me figure out how LUML could fit my work.
```
